# QuickPages AI Documentation

# 02-designSystem.md

## Purpose

This document defines the complete visual language of QuickPages.

Every page, component and interaction must follow this design system.

Consistency is more important than creativity.

The objective is to create a timeless interface that communicates professionalism through simplicity.

---

# Design Principles

Every interface should feel:

Minimal.

Editorial.

Elegant.

Purposeful.

Balanced.

Timeless.

Modern.

Calm.

Professional.

Avoid visual noise.

Avoid unnecessary decoration.

Whitespace is part of the design.

---

# Layout Philosophy

The website should breathe.

Every section should have generous spacing.

Avoid filling every empty area.

Users should naturally focus on the content.

Large margins create rhythm.

Rhythm creates elegance.

---

# Grid System

Desktop

12-column grid.

Maximum width: 1440px.

Content width: 1280px.

Horizontal padding: 80px.

---

Tablet

8-column grid.

Horizontal padding: 48px.

---

Mobile

4-column grid.

Horizontal padding: 24px.

---

---

# Border Radius

Buttons

14px

Cards

16px

Containers

20px

Inputs

14px

Images

16px

Avoid exaggerated rounded corners.

---

# Shadows

Use shadows sparingly.

Shadows should only create subtle depth.

Never use dramatic elevation.

Prefer contrast and spacing over shadows.

---

# Color Philosophy

The interface should remain mostly neutral.

Accent colors should highlight actions.

Not decorate the interface.

---

# Primary Colors

Background

#FAFAF9

Surface

#FFFFFF

Primary Text

#111111

Secondary Text

#666666

Borders

#E7E7E7

---

# Accent Color

Choose only one accent color.

Examples:

Deep Blue

Petrol Green

Dark Indigo

Muted Teal

The accent color should represent less than 10% of the interface.

---

# Typography

Typography is the primary visual element.

It should create hierarchy naturally.

---

---

# Containers

Every section should be wrapped inside a reusable container.

The content should never touch screen edges.

Maintain visual rhythm across the site.

---

# Sections

Each section should include:

Large top spacing.

Large bottom spacing.

Clear visual hierarchy.

Consistent alignment.

Breathing room.

---

# Buttons

Buttons should feel premium.

Not playful.

Not oversized.

Not futuristic.

---

## Primary Button

Solid background.

Subtle hover.

Smooth transition.

Medium weight typography.

Optional arrow animation.

---

## Secondary Button

Transparent background.

Border.

Subtle hover.

Underline animation optional.

---

# Links

Links should never rely only on color.

Hover states should include:

Underline animation.

Opacity change.

Small movement.

---

# Navigation

Sticky.

Transparent initially.

Blur after scrolling.

Thin bottom border.

Minimal height.

No oversized logo.

Navigation should disappear only if it improves the experience.

---

# Cards

Cards should feel editorial.

Generous padding.

Minimal borders.

Little or no shadow.

Large typography.

Consistent spacing.

Avoid colorful cards.

---

# Images

Images should have:

Consistent aspect ratios.

Rounded corners.

Optimized loading.

Subtle reveal animations.

Never stretch images.

Never distort proportions.

---

# Icons

Use Lucide React.

Line icons only.

Consistent size.

Consistent stroke width.

Icons should support content.

Never dominate it.

---

# Dividers

Use subtle borders.

Avoid thick separators.

Whitespace should separate sections whenever possible.

---

# Lists

Simple.

Clean.

Easy to scan.

Avoid decorative bullets.

Prefer minimal spacing.

---

# Forms

Minimal.

Accessible.

Easy to complete.

Fields should include:

Name

Email

Company (optional)

Message

Clear submit button.

Visible focus states.

---

# Tables

Avoid traditional tables.

Whenever possible, replace them with flexible layouts.

---

# Responsive Behavior

Never simply scale down the desktop version.

Reorganize layouts intentionally.

Desktop

Horizontal layouts.

Tablet

Mixed layouts.

Mobile

Vertical layouts.

---

# Responsive Typography

Text should scale smoothly.

Never overflow.

Never become too small.

Always prioritize readability.

---

# Empty States

Every empty state should feel intentional.

Use simple illustrations or typography.

Never leave blank areas without purpose.

---

# Loading States

Avoid skeleton overload.

Prefer subtle fades.

Smooth transitions.

Minimal loading indicators.

---

# Error States

Friendly.

Clear.

Concise.

Explain the problem.

Offer the next step.

Avoid technical language.

---

# Visual Rhythm

Alternate section compositions.

Image left.

Image right.

Centered.

Split layouts.

Editorial blocks.

Never repeat identical layouts multiple times.

---

# Consistency Rules

Every page should feel like part of the same product.

Spacing.

Typography.

Colors.

Animations.

Components.

Everything must remain visually consistent.

---

# Design References

The interface should feel inspired by modern creative studios.

Editorial layouts.

Luxury branding.

Minimal architecture.

High-end portfolios.

Not SaaS dashboards.

Not templates.

---

# Success Criteria

A visitor should immediately perceive:

Professionalism.

Attention to detail.

Modern design.

Visual clarity.

Confidence.

Premium quality.

Without reading a single paragraph.

The design itself should communicate those values.
