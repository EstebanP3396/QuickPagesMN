# QuickPages AI Documentation

# 03-pages.md

## Purpose

This document defines the structure, composition, hierarchy and user experience of every page and section inside the QuickPages website.

This is not a wireframe.

It is the experience blueprint.

Every section should naturally guide the visitor toward the next one.

The website should feel like a story instead of independent pages.

---

# Navigation

The navigation must remain visible across the website.

It should never compete with the content.

Structure:

Home

Work

Services

Process

About QuickPages

Technology

FAQ

Contact

Navigation behavior:

• Transparent when the page loads.

• Blur background after scrolling.

• Thin bottom border.

• Active section indicator.

• Smooth scrolling.

• Mobile menu with elegant fullscreen transition.

Avoid oversized mobile menus.

The mobile navigation should feel premium.

---

The visitor should experience the website in this order:

Every section should answer one question before the visitor asks it.

# HOME

## Objective

Create an immediate emotional impact.

The visitor should understand within five seconds that QuickPages builds premium websites.

Do not explain everything.

Create curiosity.

---

## Hero Composition

Large editorial typography.

Supporting paragraph.

Two primary actions.

Minimal visual composition.

No unnecessary illustrations.

Whitespace is the hero.

---

## Layout

Left aligned content.

Large heading.

Supporting text.

Primary CTA.

Secondary CTA.

Visual composition occupying the remaining space.

Desktop:

Two-column layout.

Mobile:

Single column.

---

## Hero Copy Direction

The title should communicate transformation rather than technology.

Avoid:

"We build websites."

Prefer:

"We design digital experiences that help businesses grow."

Generate an original variation.

Never copy examples directly.

---

## CTAs

Primary

Start a Project

Secondary

View Our Work

Primary CTA should receive the most visual attention.

---

## Hero Visual

Avoid generic mockups.

Instead create a composition using:

Project screenshots.

Minimal floating cards.

Device mockups.

Editorial grids.

Typography.

Negative space.

The visual should support the content.

Never dominate it.

---

## Scroll Indicator

Minimal.

Elegant.

Continuous.

Purpose:

Invite exploration.

# Transition to Work

# Interaction Principles

Every page should answer one question.

Every section should encourage scrolling.

Every transition should prepare the next section.

The visitor should never wonder what to do next.

The experience should feel carefully directed from beginning to end.
